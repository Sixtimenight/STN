# AI / Web3 Opportunity Radar

一个面向学生和早期从业者的机会研究工作流，用于发现 AI 应用、Web3、校园项目、社区合作和黑客松机会，并把零散线索变成可执行的每日简报。

## 工作流程

```text
固定渠道与关键词检索
        ↓
提取岗位、活动和合作线索
        ↓
回到主办方或雇主来源核验
        ↓
按匹配度、时效性和风险评分
        ↓
去重并生成每日行动清单
```

## 核验层级

1. **已核实事实**：来自雇主官网、主办方页面或官方账号。
2. **发布方自述**：奖励、客户、融资和合作等尚未独立验证的信息。
3. **分析判断**：匹配分、优先级、风险和建议行动。
4. **未核实线索**：只能作为继续调查的入口，不能直接当成事实。

## 评分维度

- 方向匹配：AI、Web3、产品、内容、社区或商务
- 身份匹配：年级、经验、语言和地区
- 时间匹配：截止日期、到岗时间和每周投入
- 证据强度：是否能回到官方来源
- 回报质量：现金、作品、资源和转正可能
- 风险成本：无偿劳动、钱包签名、充值、隐私或诈骗风险
